# Trial by Emulation

Guidance and tutorial on target trial emulation and related causal inference and statistical methods

# Usage  

People interested in the tutorial only, need but go to: https://BrownEpiHSR.github.io/tte-guide/
Those interested in reproducing all the output, may fork the package 
then run the `onetime.R` file to initialize Renv and install necessary packages.
